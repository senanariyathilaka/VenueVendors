**Vendor Venues**

This is a venue hiring and management site project designed to allow users to hire/ host their own venues for events

*instructions:*

the site is very intuitive, but the basic instructions are to initially sign up picking either the vendor or hirer role. once successfully signed up you will be directed to a specific page.

**Vendor** 

in this page you are able to create, manage all venues 

- includes the ability delete and block dates for the venues you have created
- you are also given the ability to approve applicants applying to a specific venue
- finally you can leave comments on a specific hirer applicant along with a rating

**Hirer**
- as a hirer you are able to apply for the use of a specific venue 
- add preferences for specific venues 
- search for a venue based on a set few key words
- view a history of the venues you've been accepted for
- view submitted applications

*the website is live on this link:*
  https://venuevendors-front-end.onrender.com/
